Run full system with Docker:
1) cd AttendanceSystem_completed
2) docker compose up --build
3) Open frontend: http://localhost:5173
4) Teacher dashboard: http://localhost:5173/teacher

Run locally without Docker:
Backend:
  cd backend
  npm install
  npm run dev
Frontend:
  cd frontend
  npm install
  npm run dev
AI service:
  cd backend/ai
  pip install -r requirements.txt
  uvicorn main:app --host 0.0.0.0 --port 8001
Database:
  run PostgreSQL 16 + pgvector, then execute SQL in backend/database/docker-entrypoint-initdb.d in order.
